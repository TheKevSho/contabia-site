## Variant: Pinned strip + tree

### Design stance
Same tree and numbers, but cash / GOP / neta stay pinned so collapse never hides the Nick question.

### Key choices
- Layout: 3-number strip locked under the tabs; tree scrolls underneath.
- Typography: same portal tokens; strip uses DM Serif for the three figures.
- Color: same REAL / QUINCENA / PROY. language.
- Interaction: identical collapse, tabs, palancas, cell override.

### Trade-offs
- Strong at: Nick can answer “¿voy a estar bien?” without hunting row 30.
- Weak at: strip duplicates rows that also live in the tree (two sources of the same number on one screen).

### Best for
If Thursday is mixed audience and you don’t want Claudia’s tree to bury Nick’s cash.
